### 👨‍💻 Sobre Mim

Sou um Desenvolvedor de Software com formação em **Análise e Desenvolvimento de Sistemas pelo IFRS**, apaixonado por tecnologia e focado em construir aplicações robustas e de alta performance dentro do ecossistema **TypeScript**.

Minha experiência vai desde a criação de um Painel de Controle de Disponibilidade (PCO) do zero, passando pelo desenvolvimento de aplicações web com **Next.js** para projetos de Inteligência Artificial, até a criação de aplicativos móveis para Android e iOS com **React Native**. Para me manter sempre atualizado e expandir minhas competências, estou cursando uma **Pós-graduação em Desenvolvimento Avançado em Golang com a Full Cycle**, aprofundando minhas habilidades em backend e sistemas de alta performance.

Sou um grande entusiasta de metodologias ágeis, código limpo, **Clean Architecture** e princípios **SOLID**.
